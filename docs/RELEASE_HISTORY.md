# OmniBiz — Histórico Oficial de Releases

**Documento:** `RELEASE_HISTORY.md`
**Objetivo:** Centralizar todas as versões oficiais do OmniBiz, permitindo crescimento contínuo do histórico de entregas.

---

## Como este documento cresce

Cada nova versão homologada de qualquer módulo deve receber uma entrada neste histórico, na ordem cronológica inversa (mais recente primeiro). Cada entrada segue a estrutura:

- **Versão**
- **Data**
- **Módulos entregues**
- **Status**
- **Resumo**
- **Documento de referência**

Módulos futuros previstos (Comercial, Frota, Mercado, Loja de Roupas, Restaurantes, IA, Financeiro) receberão suas próprias entradas conforme forem homologados.
