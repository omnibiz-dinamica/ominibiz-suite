# Release Notes — Funcionário — OmniBiz V1.0

> **Público:** Funcionário / Colaborador · **Data:** 2026-07-16

## O que muda para você

### 1. Tarefas mais claras
O dashboard mostra o que está pendente, em andamento e o que precisa de atenção. Um clique nos cards já leva para a lista filtrada.

### 2. Clientes "Manuais"
Alguns clientes agora funcionam em **modo Manual** — nesses casos, você não precisa apertar Iniciar/Parar. O apontamento é feito depois. O gestor lhe informa quais clientes são Manuais.

### 3. Sem mudanças no ponto tradicional
Para clientes **Start/Stop**, tudo continua igual: iniciar, pausar, retomar, concluir. GPS, foto e geo-cerca permanecem inalterados.

### 4. Recibos, férias e despesas
A busca por colaborador em telas gerenciais foi padronizada — o que você reporta não muda. Prazos e regras seguem os mesmos.

---

## O que fazer agora

- Continue registrando ponto normalmente para clientes tradicionais.
- Pergunte ao gestor se algum cliente passou para o modo Manual.
- Aproveite o dashboard como atalho para as suas tarefas do dia.

## Perguntas frequentes

- *Vou precisar refazer meu ponto anterior?* Não. Nada foi alterado no histórico.
- *Preciso instalar algo?* Não. Basta atualizar a página.
- *Perco o GPS em modo Manual?* Modo Manual não usa GPS — porque não há batida em tempo real. Isso é intencional.
